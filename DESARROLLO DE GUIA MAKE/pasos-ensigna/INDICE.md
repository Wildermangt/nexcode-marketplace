## Nota importante sobre las diapositivas

Las diapositivas **282-287** muestran la demo del docente usando el módulo
**Gmail → Send an email** (enviar un correo), que sirve para probar que la conexión
con Gmail funciona.

Para **entregar la guía** el disparador debe ser **Gmail → Watch emails**
(diapositiva 291) encadenado a **Google Sheets → Add a Row** (diapositiva 292),
tal como lo confirma la infografía de la página 294:

> `Gmail → Make → Google Sheets → Registro automático`

La diapositiva 289 muestra el orden invertido (Sheets → Gmail); el flujo correcto
según la guía es **Gmail primero**.
